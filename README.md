# daudit-media

Public host for DAUDIT report visuals — charts and images used in DAUDIT's marketing reports.

## About DAUDIT

DAUDIT is a decision audit: a cognitive audit for high-stakes decisions.
It reads the context you bring, surfaces the constraints you did not name,
checks claims against your stated premises, and leaves a typeset record of
how you actually reasoned.

It does not decide for you. It makes sure you walked the whole room before
you closed the door.

Site: https://daudit.net

Frameworks used in an audit: world model gaps, adversarial risk, theory of
mind, decision state, confidence versus evidence.
